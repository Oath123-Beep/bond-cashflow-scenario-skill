# 课程定价案例与情景示例

## 所给 PPT 第十二章例题

已知面值1000元、2年期、年票息10%、每半年付息、年化名义收益率12%并半年复利。每期利息为1000×10%÷2=50元，共4期，最后一期收到1050元。

用半年收益率6%逐期折现：

P = 50/(1+0.06) + 50/(1+0.06)^2 + 50/(1+0.06)^3 + 1050/(1+0.06)^4 ≈ 965.35 元。

该示例源自用户提供的课程 PPT，不是当前债券报价。examples/price.json 将现金流换算为每100面值的5、5、5、105元；2026-10-27运行脚本得965.35元，与PPT的965.35元一致。具体有限验证见 VALIDATION.md。

## 分期现金流情景

examples/cash-plan.json 中的债券代号、面值、日期、持仓、票息、报价、支出和费用全部是模拟假设，不是实际证券或市场报价。将事件按到账时点先后分析，需求早于到期不能用未来本金补足；首次缺口作为未覆盖记录，后期现金不能追溯消除。用户可替换成来源可追溯的公开条款和独立提供的持仓、报价与假设。

## 真实公开条款与模拟持仓

examples/real-bond-scenario.json 使用 GK25DDH2 的公开票息等条款，持仓、现金及两期支出完全虚构；假定2026-12-11票息如期到账，实际是否足额与按时未发生且不保证。该债券仅面向专业投资者中的机构投资者，不暗示普通个人可以交易。来源与页面见 references/bond-case-gk25ddh2.md。观察期截止2027-03-01，因此未知的2027年12月顺延情况不纳入本例。实际运行第一期支出后余额1,350元，第二期缺口3,650元；此为给定模拟条件的算术结果，不是行情或预测。
