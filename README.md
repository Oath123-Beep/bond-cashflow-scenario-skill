# 固定利率债券分期资金缺口与压力情景分析 Skill

**项目第一版：v0.1.0，第一周补充对照：v0.1.1。** 本版本将此前工作稿 v0.3 确定为正式迭代的起点；编号不表示本工具已达到生产级成熟度。

## 项目问题

对课程学生和固定收益研究初学者而言，持有一只固定利率债券时，未来几个日期出现资金需求：合同票息和本金能否按时覆盖？如果用户指定提前出售，利率情景、交易数量、费用及到账日期将怎样改变资金缺口？

该项目围绕用户指定的资金日期、现金流时点及信息不确定性展开。现金流匹配和压力分析已有行业应用，本项目不声称首创，也不作投资推荐。

## 课程依据

以所给《金融市场与金融机构》第十版 PPT 为主：第三章第一节现值与债券定价、第三节到期收益率与持有期收益及久期；第十二章债券定价与投资风险；第五章第二节利率期限结构、第十七章第三节资产负债管理作为扩展。

## 使用

将本文件夹作为 Skill 输入支持该格式的工具，或提供 SKILL.md 及相关资料给具备文件读取能力的助手；提供债券条款、现金支出、持仓、交易和结算条件。公开条款、实际持仓、报价和情景应分别标识来源；报价缺失只做理论情景。

可使用 Python 3 在项目根目录运行：

    python scripts/bond_cashflow.py price examples/price.json
    python scripts/bond_cashflow.py ledger examples/real-bond-scenario.json
    python scripts/bond_cashflow.py ledger examples/cash-plan.json
    python scripts/compare_scenarios.py examples/scenario-comparison.json
    python -m unittest discover -s tests -v

price 模式要求用户给出每100元面值的固定现金流、整期编号、年化名义收益率和年内付息频率，仅支持等间隔整期；ledger 模式根据用户指定的现金流、出售、权利归属、结算日和支出逐日列账，不自动生成或核验观察期现金流的完整性。需设置 analysis_through 分析截止日；超出截止日的现金流不计入。initial_cash 必须是截至 as_of 当日合同现金流已到账并计入后的余额；程序仅录入 as_of 之后的合同现金流。债券必须给出唯一、完整的到期本金现金流，且出售交易及结算均须早于该本金支付日；缺少到期本金或无法满足限制时拒绝计算。字段和计算口径见 references/method-and-data.md。

## 可手工复现的课程示例

根据所提供 PPT 第十二章债券定价例题：面值1000元，票息年率10%，期限2年、每半年付息，年化名义收益率12%并按半年复利；半年现金流依次为50、50、50、1050元。价格为 50/1.06 + 50/1.06² + 50/1.06³ + 1050/1.06⁴，约965.35元。它是课件算例，不是市场报价；持仓和支出示例则为虚构情景。

## 第一版情景对比与解释

examples/scenario-comparison.json 以公开条款为研究背景，持仓、需求、出售面值、全价、费用和成交结算日期全为假设，未验证交易日历或交易资格；票息按时支付也是假设。所有情景沿用同一初始现金、持仓、合同现金流与需求，不预测价格，也不表示投资建议。

| 情景 | 假设 | 到期未覆盖金额 | 期末现金 |
| --- | --- | ---: | ---: |
| 持有 | 不出售 | 3650.00 | 0.00 |
| 及时到账 | 假设出售面值5000、全价98、费用20 | 0.00 | 1230.00 |
| 延迟到账 | 相同出售方案在需求日后到账 | 3650.00 | 4880.00 |
| 价格压力 | 假设全价70、费用20、及时到账 | 170.00 | 0.00 |

第二笔需求为假设的2027-02-26、金额5000；输出假定同一天到账先于同一天支付。延迟到账的期末现金与此前未覆盖额可以同时存在，因为不自动追溯偿付此前缺口。全价70仅为演示压力的任意参数，不代表真实估值或可能性；本例未观测市场成交或测试交易资格。

比较工具只替换每个情景的 sales，其他基准输入一致；sales 中必须完整提供交易日期、结算日期、权益截止日、出售面值、全价和费用。当前只比较预先指定方案，未实现自动优化、交易日历、收益率边界搜索、历史回测或其他复杂债券的 QuantLib 交叉验证。示例不保证观察期外现金流记录完整。

## 第一周 QuantLib 同口径验证

2026-10-28 在 Python 3.12.14 和 QuantLib 1.44 环境下，使用课件的规则半年现金流和示例估值／结算日 2026-01-01，对照手工公式、第一版脚本与 QuantLib。QuantLib 的全价为 96.5348943873 元／每百元面值，面值 1,000 元的价值为 965.3489438730 元；手算为 965.3489438730 元，第一版脚本按分输出 965.35 元。QuantLib 与手算未四舍五入的绝对差约 1.14×10⁻¹³ 元。结果只反映一个简化样例。

验证假设：NullCalendar、日期不调整、零结算天数、ActualActual(Bond, schedule)、年票息10%、名义年收益率12%、半年复利。估值日与付息周期起点重合，应计利息为零，所以此例净价等于全价；它并未验证非付息日的应计利息或真实市场日历。这些日期及债券参数是教学设定，非真实行情。

安装可选依赖并复现（先进入本项目目录）：

    python -m pip install -r requirements-quantlib.txt
    python scripts/quantlib_benchmark.py

不安装该可选依赖时原有离线账本仍可使用。输出示例及实际运行结果见 examples/quantlib-benchmark-result.json；验证详细口径见 VALIDATION.md。
